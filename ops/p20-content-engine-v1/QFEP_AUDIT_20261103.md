# QFEP v1.0 / P20 Content Engine V1 — Evidence-based audit and pilot patch (2026-11-03)

Status: AUDIT_CANDIDATE / NOT_PRODUCTION_APPROVED. Basis: QFEP v1.0, P20 content_eval_v2, workflow_learning_v1, requirement_lock_v1, EXP-200-X1X4-01, D-056 and PR #84. No paid API/model call performed. Only this isolated audit branch changed; legacy runtime remains disabled.

## The three distinct questions
1. Is a gate structurally satisfied (files, hashes, state transitions)?
2. Does the actual manuscript obey author's instructions, substantiated claims, causal structure, unique episode insight and natural Korean?
3. Has a trusted author A2 approval occurred?

A structural CI pass is NOT manuscript quality pass or author approval. The pre-patch CI only ran dry_run, schema import, and shallow gate tests.

## Confirmed weaknesses and traceable failure cases
- **CONTENT_INSPECTION_MISSING**: gate_state._require_artifacts verifies only file existence for most stages; a file with 'ok' can pass. P20 000202 had extensive source and multiple drafts but author rejected irrelevant exhibition analogies, unsourced author experience and research-as-decoration (WL-000027~029).
- **LENGTH_PROXY**: draft_level_b/c demanded character-count growth, contradicting QFEP's explicit rejection of length as a quality surrogate. 000198 and 000202 were harmed by repetitive content, defensive caveats and examples that did not change the judgment. Pilot patch removes growth requirement; preserves changed-file requirement.
- **FREEZE_MALLEABILITY**: source_freeze initially checks current source against adjacent .sha256 once. If both were rewritten together later, it had no immutable state digest for continued verification. Pilot patch anchors the digest in 00_run_state.json and validates it on packet_validate. Still requires tamper-proof execution record to defend against malicious state-file rewrite.
- **POST_QA_EDIT**: independent_evaluation and korean_quality checked draft digests at approval time, but later packet_validate did not consistently recheck manuscript immutability. Pilot patch rejects drift after Korean QA. Any legitimate post-QA edit should reopen QA and independent evaluation with fresh digest.
- **SELF_ASSERTED_INDEPENDENCE**: independent_evaluation checks JSON claims writer_context_shared=false, writer_process_visible=false but no verified process trace or evaluator session identity. User complaint of false PASS after CNT-000198 and independent QA NOT_RUN in 000203/206 show why this must remain unverified.
- **A2_MARKER_NOT_AUTHORIZATION**: 'A2_STATUS: APPROVED' inside a text file can be forged. A2 needs a trusted user approval event, explicitly bound to approved manuscript hash. This audit does not change the authorization layer before its provenance contract is verified.
- **SCRIPT_ONLY_NO_CANONICAL_DIFF**: live canonical requirement_lock rows are not loaded or diffed by PR84's pipeline.py. Explicit LR-204-08 excludes 2006 eBay experiment in 000204, but it still appeared in the manuscript. A requirement-regression gate must read exact locked requirements and cite text spans.
- **PREPARATION_NOT_EXECUTION**: pipeline.py's executable modes are dry_run, research_only and packet_validate; full raises ONE_SHOT_FULL_DISABLED. There is no demonstrated live complete QFEP S0–S8 production flow from this scaffold. A dry-run success never proves source retrieval, drafting, blind review or A2.
- **OVER-SERIALIZATION**: QFEP is editorially concise but the V1 scaffold sets 20 ordered gates and many mandatory intermediate files regardless of actual content type. WL-000019/022 already record excessive round-trips and schema-first work delaying writing. Safely combine prewrite research into one packet and only preserve independently meaningful gate boundaries.
- **CROSS_EPISODE_HOMOGENIZATION**: 000202–000206 repeatedly converge on generic customer value/branding lessons. Distinct primary payoffs must be locked before drafting (000202 genuine vs manipulated social proof; 000203 platform survival divergence; 000204 commoditization/copycat incentives; 000205 mindset changes tactical search; 000206 intangible entertainment freshness). Use thematic novelty/overlap review, NOT a ban on the actual author's recurring philosophy.

## Verified external improvement cases — measured or directly observed, 2026-11-03 research update

Evidence ranking: controlled expert-rated script comparisons > reproducible human-evaluated long-form writing experiments > production customer case studies with reported internal metrics > vendor success stories without denominators. These are not interchangeable.

1. **ReelFramer / CHI 2024 — directly relevant to video scripts.** Problem: generating a short news video script directly from an article and a stylistic directive produced irrelevant analogies, incomplete information and incoherent scenes. Intervention: journalists first locked an intermediate **premise** with narrative framing, essential news points, characters/plot/setting; only then did the model generate the script. Controlled setup: 24 scripts (12 with premise, 12 without), six news articles, four expert raters with two independent ratings per script, seven-point rubric. Frame fidelity 5.58 -> 6.95 (p=.028), key information coverage 4.63 -> 5.50 (p=.034), narrative coherence 4.63 -> 5.92 (p=.011). Information correctness and entertainment did **not** significantly improve: distinct quality dimensions. Specific illustrative failure: a climate news skit with random disconnected jokes (4.0/7) became a consistent central metaphor (6.5/7). Transfer: QFEP S3/S4 should freeze the episode's author thesis, exact audience contradiction, essential evidence and progression before prose. Do **not** impose ReelFramer's particular character/dialogue framework on a single presenter. Primary source: https://arxiv.org/abs/2304.09653 ; primary PDF https://arxiv.org/pdf/2304.09653 ; DOI https://doi.org/10.1145/3613904.3642868.

2. **Re3 / EMNLP 2022 — long-form consistency.** Problem: same-base-model direct generation of 2,000+ word stories drifted from original premise and suffered weak long-range coherence. Intervention: plan -> recursively extend while injecting both global outline and current story state -> rerank continuations for plot and relevance -> local consistency editing. Human assessment versus similar-length direct model output showed +14 percentage points for coherent overall plot and +20 percentage points relevance to premise. Transfer: single Writer gets a *compact premise/state*, not all raw source sheets; validate narrative continuity across successive draft levels. Scope: fiction, not factual Korean YouTube presentations; cannot assume same percentage effect. Source https://aclanthology.org/2022.emnlp-main.296/.

3. **Descript Underlord / Anthropic customer case 2026 — instruction fidelity in real video editing.** Problem: rigid 'edit for clarity' pipelines could not handle user requests to edit only specific paragraphs or produce a separate composition without altering original. Intervention: open-ended editing agent + 100+ real customer tasks as an eval bank, with three independently scored dimensions: Don't break things / Do what I asked / Do it well; LLM judge calibrated against human reviewers. Across competing models, the chosen Opus 4.6 had 13–23% higher creative-intent adherence on Descript's internal test set; reportedly 8.6% more exports among agent users than non-agent users, an observational business metric not proof of causal quality gains. Transfer: enforce author instruction fidelity and untouched-span preservation first, then prose quality. Preserve 000202 user's edits, banned source exclusions and 000206 facts vs speculation; do not rewrite whole episodes on a local change. This is a vendor/customer-reported metric and model-comparison result, not a randomized harness A/B outcome. Source https://claude.com/customers/descript ; independent practical eval overview https://www.anthropic.com/research/demystifying-evals-for-ai-agents.

4. **Descript dubbing / OpenAI customer report 2026-03-06 — improve writing for spoken delivery.** Problem: semantically correct translations often made unnatural dubbed audio; earlier teams adjusted delivery speed *after* generating sentences. Intervention: sentence/pause-aware chunks with surrounding context, optimize duration and semantic meaning *during* writing, separate timing and fidelity graders with user-calibrated natural speaking windows. Percentage of segments within acceptable timing improved from 40–60% to 73–83% across languages (+13–43 percentage points); dubbed exports rose 15% in the first 30 days after release. Transfer: for Korean presenter scripts, evaluate semantic fidelity and actual speechability separately and at draft time, not as a grammar-only final polish. Do not copy dubbing segment time budgets into free-speaking monologues; these results are not an outcome of Korean script writing. Source https://openai.com/index/descript/.

5. **Read, Revise, Repeat (R3) / ACL Workshop 2022 — selective revision rather than uncontrolled complete rewrite.** Problem: one-shot rewrite cannot adapt to writer's accept/reject feedback over multiple iterations. Intervention: model proposes edits; user accepts/rejects; accepted edits become the next revision state. Their empirical test reports higher-quality revisions with fewer passes/edits compared to alternatives, with early-stage suggestion acceptance comparable to human corrections; source abstract does not provide a single universal percentage. Transfer: retain user corrections as immutable local preference/rejection pairs, route a defect to the relevant manuscript spans, protect valid neighboring text. Source and public code: https://aclanthology.org/2022.in2writing-1.14/ and https://github.com/vipulraheja/IteraTeR.

6. **LLM creative feedback limitation / ACL 2025 — diagnosis needs calibrated severity.** 1,300 deliberately damaged stories were assessed: models often gave specific broadly accurate feedback but failed to identify the **most serious problem** or when to offer negative vs positive feedback. This is a *documented failure benchmark*, not a claimed success case. Transfer: add a known-severity red-team test for the worst defect per P20 script before allowing an 'independent evaluation' PASS; false praise must fail. Source https://aclanthology.org/2025.acl-long.1254/.

7. **P20 internal EXP-200-X1X4-01 / 2026-09-30 — local exploratory evidence.** Four methods on frozen common source; blind same-project subjective evaluation: voice/editor-first X2 53/60, hook/retention-first X4 50/60, outline-first X1 48.5/60, research/talking-points X3 47/60. Research-first suffered redundant caveats and reexplanations; voice-first produced more natural delivery and progressive scenario development. Single-topic and AI-scored, not evidence of generalized quality superiority; X2+X4 combination remained an unexecuted hypothesis. Existing Google Doc: https://docs.google.com/document/d/1_1w1UD_Qz2ghL-H91f6hNSXI2jACKxvULd84SGW_xrw/edit.

### Synthesis for QFEP (candidate only)
- Most transferable intervention: lock an **author-specific premise and causal payoff** before writing. This is about *meaning* and key evidence, not fixed scene counts or a formula.
- Then develop one connected spoken draft, carrying forward current narrative state; prohibit unrelated new facts and repeated generic slogans.
- Use independent human-calibrated `DON'T_BREAK / DO_WHAT_I_ASKED / DO_IT_WELL` scoring and test known user rejections as regression cases. Detection of the worst issue takes priority over superficial style PASS.
- Split Q5 oral tests into **meaning fidelity** and **speakability**. External dubbing metrics justify separation, not copying their exact timing targets.
- Protect exact user edits and exclusions; send local revisions only to affected material. When central thesis breaks, return to S3/S4 instead of repeatedly correcting a bad paragraph.
- Across CNT-000202..206, preserve five distinct payoffs and test meaning-level overlap; generic branding as the common conclusion is a HOLD signal, not necessarily a forbidden word.
- Run controlled P20 A/B using equal author evidence and one or more blinded author judgments. Neither controlled results from unrelated populations nor vendor claims establish a P20 quality PASS.

## Proposed test portfolio (not yet implemented as end-to-end)
Structural negative fixtures: no file; empty 'ok' file; same content; shorter but improved draft; frozen source mutation incl sidecar; post-QA manuscript mutation; altered reviewer trace; forged A2; changed user exclusions.
Quality/capability fixtures: CNT-000198 false author experience and inaccurate catalog causality, 000200 approved gold, CNT-000202 irrelevant case and diluted author insight, CNT-000203 defensive financial fact-dump, CNT-000204 forbidden 2006 eBay example, CNT-000205 generic motivational copy instead of point-of-view reversal, CNT-000206 hypothesized humor preparation incorrectly asserted as observed fact.
Labels from actual author correction are ground truth. Human-like oral delivery and novel perspective require blind author comparison, not regex counts or a model's uncalibrated numerical score.
