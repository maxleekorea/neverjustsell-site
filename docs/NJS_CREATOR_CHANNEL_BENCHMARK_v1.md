# NJS Creator/Author Channel Benchmark v1

Date: 2026-10-10
Decision: D-099

## Product boundary
NJS/neverjustsell.com is Macjagga's personal-brand owned channel.
It is not the multi-author integrated knowledge platform.

Core relationship:
Media / author authority -> Course -> Community

Supporting assets:
- YouTube / Instagram / columns / briefings
- books / ebooks
- speaking / programs
- Knowledge search and saved resources
- Store / Support as utilities

## Direct benchmarks
1. Existing NJS LiveKlass
   - real author portrait first
   - simple navigation to program / classroom / open chat / book / YouTube
   - strong customer-journey copy
   - real course/product thumbnails

2. CLASS101 Creator Home — Bossunni
   - creator identity, credentials and message before product
   - course immediately below profile
   - community/message as relationship actions

3. CLASS101 Creator Home — Baejakga
   - author authority and concrete proof in profile
   - Instagram link + product directly below identity

4. CLASS101 Creator Home — Kim Jinhyang
   - personal-brand identity + publishing credentials
   - external social link + course

5. CLASS101 Creator Home — John Lee Money School
   - strong creator-specific cover visual
   - membership and community are primary
   - actual posts/content appear immediately after identity

## Shared pattern
- face/name/authority before service architecture
- short profile promise and proof
- concrete course/product cards
- direct community/message/membership actions
- mobile: cover/profile -> short identity -> CTA -> tabs -> course/community
- almost no abstract explanation of the platform itself

## NJS Home candidate hierarchy
1. Macjagga Hero
   - real author image
   - customer problem / expert thesis
   - Course CTA / Community CTA
2. Current media
   - latest YouTube / column / briefing
3. Course
   - current course with real artwork
4. Community
   - direct participation and relationship
5. Book / ebook
6. Macjagga credibility
7. Speaking / programs

## What moves down
- Knowledge stays useful but is not the Home identity.
- Store and Support stay utility surfaces.
- The five-step learning loop may remain as a lower explanatory pattern if needed, but not as the Hero's main object.
- Platform-home patterns from CLASS101/PUBLY/Naver Premium/EO are not direct benchmarks for NJS.

## Desktop/Mobile principle
Desktop and mobile share the relationship order but not the same composition.
Desktop can pair copy + author image and expose several current assets.
Mobile should surface the author, the thesis, and Course/Community actions in the first screen without a large architecture diagram.
