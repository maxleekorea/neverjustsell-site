# NEVER JUST SELL 강의 접근권한 구조

## 목표

카페24에서 강의를 구매한 로그인 회원만 강의실에 접근할 수 있고, 각 회원에게는 실제로 구매한 강의만 표시한다.

## 결론

카페24 기본 기능의 회원등급만으로는 여러 강의의 개별 구매권한을 정확하게 표현하기 어렵다. 강의 A/B/C를 서로 독립적으로 구매할 수 있기 때문이다. 따라서 구매 상품 기준으로 권한을 판정하는 별도 entitlement(수강권) 검증 계층을 둔다.

## 권장 구조

1. 카페24
   - 회원가입/로그인
   - 강의 상품 판매
   - 국내 PG 결제
   - 주문/환불 데이터의 원본

2. 수강권 검증 API
   - 카페24 회원 인증 결과로 현재 사용자를 확인
   - Admin Orders API로 해당 회원의 결제완료 주문을 조회
   - 주문 품목의 product_no와 강의 매핑표를 대조
   - 취소/환불된 상품은 권한에서 제외
   - 최종적으로 구매한 course_id 목록만 반환

3. neverjustsell.com 강의실
   - 수강권 API가 반환한 course_id만 화면에 노출
   - 권한이 없는 강의 URL을 직접 입력해도 영상 iframe을 생성하지 않음

4. Vimeo
   - 영상 스트리밍만 담당
   - 공개 범위: Embed only
   - 허용 도메인: neverjustsell.com, www.neverjustsell.com
   - Vimeo 로고/공유 기능 비활성화

## 접근 흐름

로그인 → 내 강의실 → 현재 회원 확인 → 구매 주문 조회 → 구매 강의 목록 반환 → 허용 강의만 표시 → Vimeo 재생

## MVP 판정 로직

강의 접근 허용 조건:

- 카페24 회원으로 로그인됨
- 해당 product_no의 주문이 존재함
- 결제완료 상태임
- 전체 취소가 아님
- 해당 주문 품목이 취소/환불 완료 상태가 아님

초기에는 페이지를 열 때마다 카페24 주문 API를 조회해도 된다. 트래픽이 작으므로 별도 DB 없이 시작 가능하다. 사용자가 늘면 주문결제/취소/환불 Webhook을 받아 entitlement DB를 캐시한다.

## 회원등급을 주 권한체계로 쓰지 않는 이유

카페24 회원등급 자동변경은 구매금액/구매건수 기준으로 동작한다. 특정 상품 A를 구매했는지, A+B를 구매했는지처럼 여러 강의의 조합을 독립적으로 표현하기 어렵다. 등급은 '수강회원' 같은 보조 상태에만 사용하고 실제 강의별 권한은 주문상품 기준으로 판정한다.

## 보안 원칙

- Cafe24 Client Secret/Admin Access Token을 브라우저 JavaScript나 GitHub Pages에 넣지 않는다.
- 구매 여부 검증은 반드시 서버측에서 수행한다.
- Vimeo iframe은 권한 검증 성공 후에만 생성한다.
- member_id를 브라우저가 임의로 보내는 값만 믿지 않는다. Cafe24 고객 인증 절차를 통해 현재 사용자를 확인한다.
- 환불/취소 후에는 다음 권한 확인부터 즉시 접근을 차단한다.

## 필요한 Cafe24 API 권한

최소 권한:

- 주문 읽기(READ_ORDER / mall.read_order)
- 고객 인증에 필요한 사용자 인증 흐름

초기 버전은 고객 개인정보 READ_PRIVACY 권한 없이 구현하는 것을 목표로 한다.

## 구현 상태 — 2026-09-20

완료:
1. Cafe24 앱/Client ID/Secret 연결
2. Admin API 주문 읽기 연결 및 토큰 자동 갱신
3. Cafe24 고객 OAuth 연결
4. `classroom.neverjustsell.com`을 인증/강의실 정식 도메인으로 고정
5. 서버측 브라우저 세션 생성 및 검증
6. Cafe24 주문 상품번호 기반 강의 권한 판정
7. 테스트 유료 상품 `product_no=13` 구매 권한 검증
8. 구매 회원의 내 강의실 표시 검증
9. 2개 차시 Vimeo 재생 검증
10. 익명 접근 → Cafe24 로그인 → 강의실 자동 복귀 검증
11. production cross-domain smoke 자동 검증

다음 작업은 인증 개발이 아니라 **실제 강의 상품과 콘텐츠의 운영 전환**이다.

- 실제 강의 상품번호 확정
- 전체 차시 Vimeo ID 등록
- 실제 판매 URL 활성화
- 실결제/취소·환불 권한 회수 확인
- 테스트 fixture 제거 또는 비노출 처리
