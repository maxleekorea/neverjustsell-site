# NEVER JUST SELL 강의 운영 흐름

Updated: 2026-09-24

이 문서는 일반 유료 VOD를 가장 적은 관리 작업으로 등록·판매하기 위한 운영 기준이다.

## 원칙

운영자가 매번 결정해야 하는 항목을 최소화한다.

일반 유료 VOD의 공통값은 시스템이 자동 적용한다.

- 수강기간: 결제일 기준 180일
- 환불정책: Fair-trust v1.0
- 무료 미리보기: 첫 번째 실질 본강의 1차시 전체
- 사전판매 기간 보정: 없음
- 사전판매 자동 예약/자동 종료: 없음
- 구매 수강권 만료일: 결제일 기준 자동 계산
- 환불 참고액: 실제 유료 콘텐츠 이용량을 시스템이 계산
- 실제 환불: 관리자 확인 후 Cafe24에서 처리

## 실제 운영 순서

### 1. 강의 생성

관리자가 입력할 것:
- 강의명
- 간단한 소개
- 유료/무료
- 가격
- 콘텐츠 공급자
- 강의 찾기 노출 여부

유료 강의를 만들면 Cafe24 숨김 상품 생성을 자동 시도한다.

### 2. 콘텐츠 등록

- 섹션과 차시 생성
- Vimeo 영상 업로드/연결
- 드래그로 순서 정리
- 첫 번째 실질 본강의를 1차시에 배치
- 필요하면 2차시 이후 추가 미리보기 지정

유료 강의는 1차시 외에 최소 한 개 이상의 실제 유료 차시가 있어야 게시할 수 있다.

### 3. 판매 페이지 작성

관리자가 작성할 것:
- 강사명/소개
- 추천 대상
- 배우는 내용

수강기간·미리보기·환불 안내는 공통 정책을 자동 적용하므로 매번 작성하지 않는다.

### 4. 게시와 판매

콘텐츠 준비가 끝나면 강의 게시.

판매 방식:
- 바로 판매: 판매 중
- 짧게 선판매: 사전판매
- 아직 판매하지 않음: 준비 중
- 신규 판매 중지: 판매 중단

사전판매를 정식 판매로 바꾸는 것은 관리자가 필요할 때 한 번 클릭한다.
별도 오픈 예약일이나 Cron은 사용하지 않는다.

### 5. 판매 후 관리

일상적으로 확인할 화면은 수강생.

시스템이 자동 관리하는 것:
- 구매 주문 확인
- 수강권 생성
- 결제일 기준 180일 종료일
- 진도/시청시간
- 구매 당시 가격·정책 snapshot
- 주문 취소·환불에 따른 수강권 회수
- 환불 참고 이용률/금액

예외적인 경우에만:
- 관리자 수동 수강권 부여
- 관리자 수강기간 연장/회수
- 환불 상세 검토

## 관리자 화면에서 기억할 순서

기본 정보 → 콘텐츠 → 판매 페이지 → 판매 설정 → 수강생

화면 상단의 다음 할 일 안내를 따라가면 된다.

고급 설정은 복구나 기술 확인 때만 사용한다.

## 의도적으로 만들지 않는 기능

현재 규모에서는 다음 기능을 만들지 않는다.

- 강의별 환불정책 버전 수동 변경
- 일반 VOD의 강의별 수강기간 수동 조정
- 사전판매 오픈 예약 스케줄러
- 사전판매 구매자의 수강기간 보정
- 환불 자동 승인/자동 실행
- 복잡한 패키지·구독 환불 산식

실제 필요가 발생할 때만 추가한다.
