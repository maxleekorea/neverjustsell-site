## 전문 기준

- ONS 서비스 매뉴얼: 제목은 사용자가 하려는 일을 명확하게 앞에 배치. https://service-manual.ons.gov.uk/content/writing-for-users/plain-language
- GOV.UK: 모든 페이지는 검증 가능한 사용자 요구에 답하고, 링크는 목적지를 이해할 수 있어야 함. https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/plan-manage-content/identify-user-needs/
- UK Home Office UX: 링크 명칭은 도착 장소와 행동을 예측 가능하게 작성. https://design.homeoffice.gov.uk/accessibility/page-structure/links

## 모바일 문제 및 해결

- 지식·자료는 첫 정보 행동을 검색으로, 다음을 공개된 사례/용어로 배치. 실제 데이터 그룹이 없을 때 잘못된 바로가기 표시 금지.
- 강의 대표 썸네일은 텍스트가 포함된 실제 이미지이므로 16:10 강제 crop을 제거하고 원본 종횡비를 유지.
- 콘텐츠는 게시되지 않은 글을 상단 대형 카드를 만들어 꾸미지 않음.
- PC는 실제 콘텐츠에 맞춘 2열/에디토리얼 정보구조, 모바일은 1열 사용. 모든 화면 동일 카드 반복 금지.
- 자동검사 CI 예전 문구 존재 조건을 새 기능 검증 조건으로 교체. 최신 4종 워크플로 통과 확인.
- 캡처 환경은 대표 폭 PC 1440, 모바일 390. 360/320 및 실제 모바일 브라우저 사용성 검증은 별도 Gate.
